# Atomic Drift Tuner Privacy Policy

Atomic Drift Tuner (ADT) is designed primarily as a local Windows application.

## Core privacy rule

**ADT will not transfer information to other networked systems unless specifically requested by the user or the person installing or operating it.**

ADT does not automatically upload telemetry sessions, saved tunes, Assetto Corsa setup files, support bundles, local logs, or per-car Desired Behavior data.

## Data stored locally

ADT may store local application data such as:

- application settings and configured paths;
- tuning profiles and calibrations;
- per-car Desired Behavior targets;
- telemetry sessions recorded by the user;
- diagnostic logs;
- generated support bundles.

This data is stored on the user's computer and is not automatically uploaded by ADT.

## User-requested network features

### Update checking and downloads

When the user requests an update check or download, ADT communicates with GitHub / GitHub Releases for the public Atomic Drift Tuner repository.

Repository: <https://github.com/T3ddyGrahams/AtomicDriftTuner>

GitHub's privacy practices are governed by GitHub's own privacy statement.

### ADT Remote

ADT Remote is a local-network companion interface served by the Windows ADT application. It is intended for devices on the same private LAN.

ADT Remote is not intended to be exposed directly to the public Internet. ADT does not automatically publish the local remote interface to an external service.

### Share Codes

Portable ADT Share Codes can be created, copied, pasted, decoded, and reviewed locally. Creating or copying a portable share code does not by itself upload it.

If ADT provides an online Share Code service in a release, use of that service is user-initiated and should be clearly identified in the UI and release documentation before data is transmitted.

## Diagnostics and support exports

ADT can generate a local support bundle. Support bundles are not automatically uploaded.

The user decides whether and how to share an exported support bundle.

## Telemetry

Assetto Corsa telemetry used by ADT is read locally from the simulator and may be recorded locally when the user starts a recording. Recorded telemetry is not automatically transmitted to an external service.

## Third-party software and services

ADT interoperates with or references third-party products and services including GitHub, SimHub, AZOM, MOZA Racing software/hardware, and Assetto Corsa. Those products and services have their own privacy practices. ADT's policy does not replace third-party privacy policies.

## Changes to this policy

If a future ADT feature introduces a new type of network transfer, this policy and the relevant user-facing documentation should be updated before that behavior is included in a public release.
