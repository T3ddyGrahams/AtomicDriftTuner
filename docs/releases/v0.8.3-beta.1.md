# Atomic Drift Tuner v0.8.3-beta.1 — Adaptive UI & New App Icon

This beta makes ADT easier to use on portrait monitors, ultrawide displays, and smaller windows. Important actions stay accessible while longer settings pages scroll, and ADT now has its own application icon.

## What's changed

- Dashboard cards rearrange into fewer columns as the window narrows.
- Navigation can be hidden with the menu button. On wider windows, drag its divider to adjust the navigation width; on narrow windows, it opens over the page.
- Dashboard Save Profile stays above the scrolling content.
- AC Setup keeps Save for This Car and Save ADT Setup in a separate action area. Baseline controls and Desired Car Behavior sliders stack when space is limited.
- Setup, telemetry, Tuning Assistant, Share Codes, AZOM, Appearance, and Updates have improved scrolling and wrapping controls. Wide tables can scroll horizontally.
- Embedded pages retain their local styles and named-control bindings. Hidden dashboard actions are removed from keyboard navigation while a tool is open.
- Per-monitor display scaling and monitor work-area sizing support moving ADT between differently sized displays.
- New ADT icon for the application, title bar, shortcuts, and installer, based on the maintainer's artwork.

Existing tuning, saving, and hardware-write safeguards are retained. Save ADT Setup still requires valid generated recommendations; changing setup inputs requires regeneration.

## Install or update

Choose the installer EXE, or extract the portable ZIP into a fresh folder and run AtomicDriftTuner.exe. Both packages are self-contained Windows x64 builds; no .NET SDK is required.

The installer upgrade was verified to preserve existing ADT saved-data files. This package includes ADT SimHub Bridge v0.8.3-beta.1. For bridge installation or repair, fully close SimHub, use ADT's Setup & Paths > Install / Repair Packaged Bridge, then restart SimHub.

## Validation

- 156 layout geometry assertions across ten tool pages, including narrow, short, portrait, and ultrawide layouts.
- All 18 existing regression scenarios passed, including the 8,000-combination tuning range check.
- Packaged app launch, keyboard navigation toggle, and installer upgrade verified; installed file hashes matched the tested package and saved-data files were unchanged.
- The maintainer reported successful hands-on testing of the installed UI preview before publication.

This remains a beta for wider display and hardware testing. The layout checks do not cover every live interaction; physical wheelbase Apply/Revert and installed SimHub bridge replacement were not repeated during this UI pass.

Report issues through [GitHub Issues](https://github.com/T3ddyGrahams/AtomicDriftTuner/issues), including ADT version, affected page, monitor orientation/scaling, and reproduction steps. Include a diagnostics support bundle when useful.
