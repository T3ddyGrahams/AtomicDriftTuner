# Atomic Drift Tuner v0.9.0-preview.3 — Intelligence, Guided Workflow & Appearance

This public beta preview combines deeper telemetry diagnosis, driver-specific run history, guided setup and broader color customization. The latest appearance update does not change the tuning or telemetry intelligence added in the earlier previews.

## What's included

- Phase-aware diagnosis for initiation, transitions, front/rear grip balance, self-steer, stability and oscillation, connected to the recorded Desired Behavior profile.
- Driver-specific run/tune history, before/after comparisons and saved feedback to help assess whether a change improved the same car for that driver.
- Setup guidance that adapts to SimHub/AZOM availability, plus Your Next Step guidance from baseline through recording and comparison.
- 72 appearance color roles, including 35 new controls for section headings, labels, expanders, buttons, sliders, scrollbars, menus and tooltips. Fixes unreadable dark headings in Core + Effects.
- ADT Remote follows the saved desktop palette after refreshing its page.

## Download and upgrade

- **Installer:** `AtomicDriftTuner-0.9.0-preview.3-setup.exe`.
- **Portable:** extract `AtomicDriftTuner-0.9.0-preview.3-portable.zip` to a folder, then run `AtomicDriftTuner.exe`.
- Both packages are self-contained Windows x64 builds. The bundled ADT SimHub Bridge is version `0.9.0-preview.3`; its functional source is unchanged from the preceding beta.
- Keep a backup of your ADT settings/profiles and car setups before updating. Close ADT before running the installer. Close SimHub before using Install / Repair Packaged Bridge, then restart it.
- Previous beta downloads remain available. If reverting, use a separate portable folder and your pre-update data backup; backward compatibility of newly saved run history has not been verified.

## Validation and beta limitations

- Passed 167 theme assertions, 252 layout assertions and 50 regression scenarios, including 8,000 built-in tuning combinations.
- The final portable ZIP was extracted into a clean folder containing spaces; the app opened with a responsive main window and closed normally. All ten packaged files match staging, and app/bridge/installer versions agree. Both projects' NuGet vulnerability checks completed with no vulnerable packages reported by the configured sources.
- The maintainer chose to release this preview before completing the full hands-on packaged-build and live-driving acceptance checklist. Installer upgrade, mixed-monitor interaction and live SimHub/AZOM Apply/Revert remain field-test targets, not verified compatibility claims for this preview.
- Diagnosis quality depends on telemetry quality and comparable driving conditions. Before/after scores are evidence to review, not proof of causation or automatic optimization.
- Color controls apply to shared element roles. Windows-managed dialogs/title bars and artwork are outside the palette.
- This build is unsigned; code signing is not enabled yet.
