# HUGE UPDATE — Atomic Drift Tuner v0.9.0-preview.30

**This is a HUGE update from public preview.17.** ADT gains easier gearing goals, deeper Gearing & ECU run review, read-only car-data analysis, and clearer feedback about when a recording has enough evidence. It also includes the Pit House crash-containment, recording, setup-capture and pit-staging fixes developed through preview.30.

## What is new

- **Gearing for the corners you drive:** Choose the gear you want for tight corners and the gear you want for long sweepers. ADT compares both speed windows against the car's actual final-drive presets and explains compromises. It detects fixed gears, individual gear selections, preset gearboxes and fixed final drives. Individual gears remain as saved; this planner changes only final drive.
- **Help with speeds and RPM:** Choose mph or km/h and save a default for new gearing targets. If you do not know your speeds, select a representative saved run to fill typical speeds for your chosen gears; each selected gear needs at least ten seconds of reliable drift evidence. Supported base engine torque curves provide a provisional RPM starting estimate, with a manual override. Example speed targets are not personalized recommendations, and the engine estimate does not model ECU, turbo or script effects.
- **Gearing & ECU analysis:** Review RPM and speed by gear and drift phase, repeated high-throttle observations, recorded gearing goals, and supported ECU selections. New run/tune snapshots retain that context. Before/after review shows what changed and suggests controlled tests when evidence is sufficient; it does not measure horsepower or prove that a gearing or ECU change caused an improvement.
- **Understand more of each car:** ADT reads supported unpacked car data and ordinary `data.acd` archives into memory, shows sources and saved-setting meanings, and preserves readable sections when an independent section is malformed. Packed and unpacked copies can coexist when their supported files match exactly. ADT does not edit physics files, execute car scripts or guess protected/custom mappings.
- **Know when to review:** Desktop, in-game companion and touchscreen show missing evidence, progress, and **READY TO REVIEW** or **READY FOR PARTIAL REVIEW**. Useful time accumulates across shorter corners and drifts. Optional PC/device chimes and an in-game notification help you notice readiness; recording continues until you stop and save. Partial review keeps missing evidence clearly marked.

## Fixes included

- Buffer telemetry in the background so busy interface updates do not discard intermediate samples. Genuine gaps remain visible; old recordings cannot regain missing samples.
- Preserve usable initiation and transition evidence when optional wheel-slip readings are invalid. Initiation timing still requires three complete entries.
- Contain native MOZA SDK crashes/timeouts in a separate helper process so desktop ADT can show an error instead of closing. A failed read clears stale choices; uncertain writes are not automatically retried.
- Improve CSP setup-capture compatibility and handle supported unnamed numeric values without pretending to know which control they represent.
- Correct standard camber saved-value ranges and steps across generation, file export and pit staging.
- Isolate conflicting car setup definitions. For example, duplicate brake-bias definitions no longer erase a valid rear anti-roll-bar range or block unrelated gearing calculations. The conflicting control remains unchanged with an explanation; required gearing conflicts still block calculation.
- Recognize unsupported adjustable engine limiters before making fixed-limiter gearing estimates.

## Downloads and upgrading

- **Windows installer:** `AtomicDriftTuner-0.9.0-preview.30-setup.exe`.
- **Portable ZIP:** `AtomicDriftTuner-0.9.0-preview.30-portable.zip`. Extract it fully, then run `AtomicDriftTuner.exe`.
- **Separate companion:** `ADTCompanion-0.4.0-preview.4.zip`. Both desktop downloads already contain this companion.
- **Checksums:** `SHA256SUMS-0.9.0-preview.30.txt`.

These are self-contained Windows x64 packages. Back up your ADT data and car setups, close ADT, then update. Existing user data is retained; installer and portable copies use the same data folders for the current Windows user. Packages do not include developer settings, recordings, credentials or vendor MOZA SDK binaries. The application binary is the tested preview.30 build; distribution guides have been refreshed for this public release.

**Updating from preview.17: update the companion too.** Exit the AC driving session, use **Remote → Install / Update Companion**, then start a fresh session. Desktop installation alone does not update the game's companion. If using SimHub/AZOM, close SimHub, use **Install / Repair Packaged Bridge** for bridge **0.9.0-preview.30**, then restart SimHub.

Reload your intended baseline before generating/staging a setup. Record a fresh baseline run after updating so new evidence, target and source snapshots are available. Car changes still require an explicit setup load or companion **Pit setup → Save & Apply Tune** while stationary in editable pits. Selecting goals or generating recommendations does not change the car live.

## Beta testing status

**Beta preview; unsigned installer.** Preview.30 passed 341 regression groups and 58 focused pit/gearing UI assertions, plus package/version checks. Read-only installed-car reproductions verified the reported staging and gearing errors. Automated tests and these reproductions do not certify every car, CSP version, display or wheelbase.

Pit House hardware read/apply/restore remains experimental and needs configuration-specific testing. Protected/custom physics, unsupported limiters and ambiguous mappings retain explicit limitations. The broader tuning-engine audit is still open: camber serialization and limiter checks are partial corrections, and recommendation attribution should not be treated as proven learning. Compare repeated, similarly driven runs and change one thing at a time.

Use the [preview.30 testing checklist](https://github.com/T3ddyGrahams/AtomicDriftTuner/blob/main/docs/testing/v0.9.0-preview.30-checklist.md) and [compatibility tracker](https://github.com/T3ddyGrahams/AtomicDriftTuner/blob/main/docs/testing/v0.9.0-preview.30-compatibility.md). Report your versions, car, relevant hardware/software, exact steps and result through GitHub Issues. Keep pairing tokens and private recordings out of public reports.
