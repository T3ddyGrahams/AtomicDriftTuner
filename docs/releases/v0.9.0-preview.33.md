# Atomic Drift Tuner v0.9.0-preview.33

**G27 support, clearer recommendations, and before/after setup comparisons.** This beta includes the improvements developed since public preview.30 and uses the same verified preview.33 installer and portable build tested locally.

## Logitech G27: a dedicated legacy-software workflow

- Select **Logitech G27 (legacy Profiler)** as your wheelbase, then open **Wheelbase Settings**. ADT selects the integrated G27 rim and its manual Logitech provider.
- Record all eight Logitech controls: Overall Effects Strength, Spring Effect Strength, Damper Effect Strength, Centering Spring Strength, Degrees Of Rotation, Enable Centering Spring, Report Combined Pedals, and Allow Game To Adjust Settings. Effect strengths accept 0–150%; rotation accepts 40–900°. These are allowed ranges, not recommended maximums.
- Save the seven AC FFB baseline values alongside your Logitech plan. Step-by-step instructions explain entering and checking the settings in legacy Logitech Gaming Software / Profiler and AC. SimHub/AZOM and Pit House are not required for this workflow.
- Keep G27 plans with saved tunes, share codes and confirmed FFB recordings. Before/after review shows percentages, rotation degrees and switch states, clearly labelled as driver-entered plans.
- Use the existing matching **AC gain calibration** with your entered baseline. G27 generation does not translate MOZA controls into Logitech settings or invent physical torque and wheel-response scores. Unmapped feedback sliders are disabled.

**This first G27 version does not automatically read or apply Logitech settings.** Saving a plan in ADT changes only the plan. Enter and verify it manually in Logitech and AC. The optional provisional starting point is a test baseline, not an automatically optimized tune. Real G27 hardware acceptance and the tester's exact legacy software version still need confirmation.

## See exactly what changes

**Your setup changes** now appears when reviewing a full generated car setup, one focused adjustment, and recorded runs in **Tuning Assistant → Before / After**.

- See a readable setting name, before value, recommended or recorded-after value, difference, and explanation together.
- Changed settings stand out. **Show all settings** includes unchanged controls.
- Proposed changes use the existing recommendation reasons. Recorded comparisons show what was captured; they do not invent a reason or claim each setting caused an improvement.
- Missing values say **Not captured**. Verified gearing/ECU mappings retain each run's own meaning. Unknown mappings retain saved values rather than guessed units. G27 plans, generated FFB targets and captured car settings have distinct labels.
- Layouts wrap and scroll for smaller, portrait and wide displays.

## Clearer saved-run recommendations

After saving a confirmed run, open **Tuning Assistant → Your next step → Review one car setup change**. Choose the setup used in that run, review one supported adjustment and its tradeoff, then save a separate test setup or stage it for an explicit pit action. ADT checks the recorded setup and car-data context before offering the test, tracks the exact settings being tested, and explains when there is not enough evidence for a change.

The existing telemetry diagnosis, Desired Behavior, car setup, gearing/ECU calculations and comparison scoring are preserved. Saving or staging still requires an explicit setup load or companion **Pit setup → Save & Apply Tune**; it does not change the car live.

## Compatibility fix

Changing cockpit driver-eye position or pitch no longer triggers a false packed/unpacked conflict when all other supported car content matches. Other physics differences still require resolution. ADT does not edit your car or camera files.

- **Checksums:** `SHA256SUMS-0.9.0-preview.33.txt`

Windows x64, self-contained beta packages; installer remains unsigned. Close ADT before updating and reopen to verify **0.9.0-preview.33**. Existing user data is retained; portable and installed copies use the same data folders for the current Windows user. Packages contain no developer settings, recordings, credentials or vendor SDKs. Companion **0.4.0-preview.4** is unchanged from preview.30; no companion reinstall is needed if that version is already installed. **For the G27 tester:** select the G27 wheelbase, choose **Car + FFB** in Setup & Paths, and open Wheelbase Settings. Copy your current values, save the ADT plan, generate/review the AC values, and verify the actual active Logitech/AC settings.
