# Atomic Drift Tuner v0.9.0-preview.38

**HUGE UPDATE — track tools, guided driver feedback and major Telemetry Intelligence 2.0 improvements.** This beta brings the work from previews .34–.38 into the main ADT app, including the track tools previously tested in a separate developer build. It uses the same verified preview.38 installer, portable package and companion installed locally.

## Tell ADT how the change felt

Open **Tuning Assistant → Before / After → Quick driver review** after a setup test.

- Answer **Better / Same / Worse / Couldn't judge** for questions tied to the goals saved with your run and the change you tested. No answer is preselected.
- Tell ADT whether a new problem appeared and optionally add notes.
- Get a clearer next step: keep and verify, repeat the test, investigate disagreement, review a tradeoff, consider the baseline, or review another supported adjustment.
- Save the review with the exact run and baseline. Earlier feedback remains in history; switching cars, goals or tests cannot silently reuse unrelated answers.
- **Review next supported test** opens the existing exact-value setup preview when the evidence supports another adjustment. Saving feedback never applies or restores settings in game.

Driver feedback and measured evidence stay distinct. If they disagree or the comparison is incomplete, ADT explains what still needs checking.

## Track maps, section goals and pass comparisons

Open **Tuning Assistant → Track & sections** after saving a fresh recording with position data.

- View the route you drove and mark a named section to review.
- Set an optional body-angle range, preferred gear and reference-line offset for that section.
- Compare complete passes, with before/after paths and measurements for line, angle, speed, gear and pedal use.
- Save feedback for an individual section and pass pair separately from the whole-run review.
- Keep using core telemetry when position data or optional track AI context is unavailable. Missing positions are never filled with invented data.

The normal **ADT Companion 0.5.0-preview.1** now supplies position capture. No separate Track DEV app or different Remote port is needed. Maps show recorded routes; an optional AI spline is context, not a recommended drift line. Section comparisons describe what changed and do not prove a setup change caused it. Older recordings without positions cannot produce a map.

## Stronger Telemetry Intelligence 2.0

- **Verify the actual setup test:** ADT records the intended controls and values, then checks the captured before/after change. Wrong amounts, extra changes, mismatched captures and stale plans cannot validate the recommendation. Improvement must relate to the intended measurement.
- **Understand where a pattern happens:** initiation, transitions, sustained drift, normal cornering and FFB saturation are reviewed by speed and direction, with available throttle/brake/clutch context. Find the detail under **Advanced telemetry → Phase Evidence → Where the pattern happens**.
- **Handle conflicting evidence:** ADT asks for a more comparable repeat when conditions disagree or substantially different pedal use makes a setup cause uncertain. Useful driving time accumulates across shorter sections.
- **Keep adjustments legal:** generation, setup export and pit staging share verified limits and steps for supported setup formats. Unsupported mappings and values that cannot be saved precisely remain held with an explanation.
- **Support adjustable rev limits in gearing:** supported limiter selections in the saved setup now inform RPM estimates and final-drive planning. Unknown ECU/script overrides remain unverified.

These are further Intelligence 2.0 milestones. ADT does not yet learn optimal numeric settings automatically from accumulated reviews. Existing G27, SimHub/AZOM and Pit House workflows remain available; this update does not expand hardware SDK support.

## Update before your first drive

1. Close ADT, install this update or fully extract the portable ZIP, then reopen and check **0.9.0-preview.38**. Existing main settings, tunes, drivers and history are retained.
2. **Close the Assetto Corsa driving session and update ADT Companion to 0.5.0-preview.1** through **Remote → Install / Update Companion**, or use the included Content Manager ZIP. Content Manager can stay open. Older companion versions cannot provide the new position channel.
3. Start a fresh AC session and enable/open the normal ADT Companion. Check the Recorder's **TRACK** status, record and save a baseline, then test one supported change and record a comparable repeat.
4. Use **Quick driver review** for the setup test and **Track & sections** for a recorded section. Click **Save quick review** to retain your answers.

Remote remains on the existing configured port, default **5190**. Position capture does not require Remote pairing; setup capture, recording controls and pit actions retain their paired connection. The bundled SimHub bridge is **0.9.0-preview.38**, with unchanged logic. Separate developer-build data is not automatically copied over main-app data.
