# v0.9.0-preview.3 tester checklist

Start with the checks relevant to your setup; report Pass, Fail, Blocked, Not run or N/A (with reason). This preview was released at the maintainer's request before full hands-on acceptance. Automated results do not verify live hardware compatibility.

## Quick first test

1. **P3-INSTALL:** Back up ADT data and car setups. Install the preview or extract the portable ZIP into a new folder. Confirm version 0.9.0-preview.3, startup and your saved settings/profiles. For an upgrade, record the previous version.
2. **P3-GUIDE:** Open Setup & Paths and answer the SimHub/AZOM availability questions accurately. Confirm the instructions and Your Next Step match your setup. Non-bridge tuning should remain usable without those integrations.
3. **P3-COLOR:** In Appearance, change Section headings, field labels and a control color. Check Core + Effects, save, close and reopen ADT, and confirm the theme persists. Try Cancel/close without saving and confirm the previous saved theme returns.
4. **P3-LAYOUT:** Resize on portrait and ultrawide monitors, move between displays/scaling levels and use keyboard navigation. Saving car tunes and Appearance changes should stay reachable.
5. **P3-TUNE:** Select the intended car/rig/driver and Desired Behavior; generate a tune. Confirm the displayed context, readable recommendations and next-step instructions.

## Driving and comparison (when available)

6. **P3-RECORD:** Record and save a representative baseline. Reopen it in Tuning Assistant; check phase diagnosis, confidence/data limitations and recorded Desired Behavior context.
7. **P3-COMPARE:** Choose one recommended change, record a comparable follow-up with the same car, driver and track, and compare the two runs. Verify tune snapshots, results and saved feedback survive restarting ADT. Report whether the change actually felt better, worse or mixed.
8. **P3-CONTEXT:** Change car or driver and confirm history/recommendations are associated with the appropriate context. Sparse or mismatched evidence should not be presented as a proven improvement.
9. **P3-BRIDGE:** If using SimHub/AZOM, close SimHub before bridge installation, then restart it. Record exact versions. In a suitable test environment verify read, an intentional Apply, readback, failure reporting and Revert. Skip live writes if unavailable.
10. **P3-REMOTE:** Pair on your private LAN, refresh after saving a desktop theme and confirm readable status/controls. Stop the server when finished.

The [previous checklist](v0.8.3-beta.1-checklist.md) remains a useful regression procedure for AC setup, diagnostics, support packages, reconnects and recovery; record results under **this preview's version**, not the previous release.

## Report

Use the [Beta Test Report](https://github.com/T3ddyGrahams/AtomicDriftTuner/issues/new?template=beta_test_report.yml) or [Bug Report](https://github.com/T3ddyGrahams/AtomicDriftTuner/issues/new?template=bug_report.yml). Include version/build type, Windows, monitor resolution/orientation/scaling, applicable rig/car/software versions, case IDs, exact outcomes and reproduction steps. Use Unknown or N/A for missing context. Results are reviewed in the [compatibility tracker](v0.9.0-preview.3-compatibility.md).
