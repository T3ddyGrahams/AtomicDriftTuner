# Preview.33 tester checklist

Record ADT/Windows/CSP versions, wheel model, exact wheel-software name/version and car folder ID. Hardware acceptance is pending; automated checks are not a substitute for the tests below.

## G27 and legacy Logitech software

- [ ] Select G27 on the dashboard. Confirm the integrated rim and legacy Profiler provider are selected.
- [ ] Choose Car + FFB in Setup & Paths. Open Wheelbase Settings; all five numeric controls and three switches match the active Logitech profile.
- [ ] Check that the form reaches 0–150% for effect strengths and 40–900° for rotation. Do not apply extreme values merely to test form limits.
- [ ] Copy actual Logitech/AC settings into ADT, save and reopen. Confirm all values persist. The optional starting-point button fills the form but does not save/apply automatically.
- [ ] Verify the active Logitech profile, since AC profile settings can override Global Device Settings. Enter and verify the plan manually; ADT must not change the wheel merely by saving, generating or opening Remote.
- [ ] Match AC rotation and verify full steering, throttle, brake and clutch travel, with independent throttle/brake axes when combined pedals are off.
- [ ] Confirm generated AC FFB matches the entered baseline plus any shown AC gain calibration. MOZA torque/damper/wheel-speed targets must not appear as G27 instructions.
- [ ] Record a confirmed baseline. Change one item deliberately, update the ADT plan, regenerate and verify the actual values before recording the second run.
- [ ] Before / After → Your setup changes → Show all settings shows the correct before/after plans, unchanged values, percentages/degrees and switches. These must be labelled as plans, not hardware readbacks.
- [ ] Remote tune review shows the G27 plan; recording/car controls work, but AZOM read/apply is unavailable for G27.

## Car setup and comparison

- [ ] Saved-run review shows a clear next step and, when supported, Review one car setup change.
- [ ] Choose the setup used in the run. Confirm one proposed setting family, before/after values and the explained tradeoff. Unsupported or mismatched evidence must give a reason rather than an invented change.
- [ ] Save a separate test setup or stage an explicit pit action. Confirm saving/staging alone does not apply anything in game.
- [ ] Capture or attach the actual test setup in the second run; compare it against the baseline. Missing values remain Not captured.
- [ ] Show all settings includes unchanged controls. Review controls remain accessible on a small or portrait display.
- [ ] If applicable, cockpit eye-position/pitch changes alone do not block otherwise matching packed/unpacked car data. Other physics differences are still flagged.

Report expected behavior, actual behavior and repeatable steps. Include screenshots of the relevant controls, with private paths/tokens removed. For failed comparisons, include the displayed conditions/limitations. Keep logs and recordings private unless deliberately sharing them.
