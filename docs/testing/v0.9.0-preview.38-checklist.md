# Preview.38 tester checklist and compatibility tracker

This release combines the main-app track tools and driver feedback with the Intelligence 2.0 improvements from previews .34–.37. Record ADT/Windows/CSP versions, car folder ID, track/layout, wheel and wheel software before testing. Automated fixtures do not establish real driving compatibility.

## Upgrade and connection

- [ ] Desktop shows **0.9.0-preview.38** and normal ADT Companion shows **0.5.0-preview.1**. Update the companion with the driving session closed, then start a fresh session.
- [ ] Existing settings, drivers, tunes, recordings and reviews are available. Main Remote pairing and its configured port still work.
- [ ] Recorder TRACK status receives fresh positions. Confirm capture with the normal companion visible and hidden.
- [ ] With position unavailable or an older companion, core recording and existing supported setup/pit controls still work; no position evidence is invented.

## One setup change and driver feedback

- [ ] Save a confirmed baseline using the actual loaded setup, driver, conditions and Desired Behavior.
- [ ] Review one supported adjustment. Check the current/proposed values and tradeoff; save a separate setup or stage an explicit pit action.
- [ ] Saving/staging alone does not apply a tune. Load it or explicitly use the companion's pit apply action before the next run.
- [ ] Record a comparable repeat. Before / After verifies the intended controls, values and captured setup coverage. Extra or wrong changes remain unverified.
- [ ] Quick driver review asks goal-relevant questions with no default answers. Try Better, Same, Worse and Couldn't judge, including the new-problem question.
- [ ] Disagreement, missing evidence and tradeoffs stay visible. An improvement in an unrelated measurement does not validate the intended test.
- [ ] Save a review, close/reopen and switch baselines. Answers return only for the exact same context; earlier reviews remain in history.
- [ ] When offered, Review next supported test opens a guarded exact-value preview or explains why another recording is needed. It does not automatically save, stage or apply a tune.

## Track sections

- [ ] Record at least three passes through a familiar section with approach and exit evidence. Confirm the displayed route matches where the car went.
- [ ] Mark a continuous section at least two seconds and 20 metres long. Save an angle/gear goal and verify the saved reference and selected pass times.
- [ ] If experimenting with an offset line, inspect the green aim and choose the intended side. ADT does not know corner-outside direction or usable road width.
- [ ] Before/after pass colors, section measurements and gear units are understandable. Same-run passes describe consistency, not a setup change.
- [ ] Compare separate recordings under the same conditions. Missing identity, direction or setup evidence and substantially different speed/pedal use keep attribution inconclusive.
- [ ] Save section feedback and switch section revision or pass pair. Feedback stays scoped to that exact section and comparison.
- [ ] Try a track with usable AI spline data and one without it. An absent spline does not prevent reviewing the recorded route.
- [ ] Pause, replay, reset/teleport, reverse or interrupt the connection during a test. Gaps and invalid motion must split evidence rather than create a complete pass across the interruption.
- [ ] Older recordings without position still open; they explain why no track map can be shown.

## Other changes since preview.33

- [ ] Phase Evidence → Where the pattern happens shows speed/direction and available pedal context using the selected mph/km/h preference.
- [ ] Repeated shorter sections accumulate useful evidence; absent front-response or entry evidence remains clearly identified.
- [ ] Conflicting driving conditions request a comparable repeat rather than a blanket whole-car adjustment.
- [ ] Supported setup controls use valid limits/steps through preview, saved file and pit action. Unsupported mappings remain unchanged and explained.
- [ ] On a car with a supported adjustable limiter, Read car and suggest RPM range uses the saved selection. Gearing export preserves it; unsupported script/ECU effects remain unknown.
- [ ] Quick review, map controls, comparison details and save buttons remain reachable at narrow, portrait and wide window sizes with the selected theme.
